# Upstream source

Image data, the VGA sync generator, and the testbench template originate from
[pongsagon/teach_hw](https://github.com/pongsagon/teach_hw/tree/edc6acb9e620dc71439adef5c2aecab1f90b84f6).

The image memory files are copied unchanged. The testbench and Makefile are
adapted for this project. The upstream Apache-2.0 license is included in
`LICENSE`; existing copyright notices are retained in the RTL.
